PALHA SHOTS — WEBSITE V1
=========================

This folder is a complete static website. No paid hosting or website builder is required.

QUICK PREVIEW
1. Open index.html in a desktop browser.
2. On some phones, previewing local website files is limited. Publishing it will display normally.

FREE PUBLISHING OPTIONS

OPTION A — Netlify Drop (easiest)
1. Unzip palha-shots-site.zip.
2. Go to https://app.netlify.com/drop
3. Drag the entire "palha-shots-site" folder onto the page.
4. Netlify will publish it at a free *.netlify.app address.
5. Create a free Netlify account if you want to keep/control the site and change the generated site name.

OPTION B — GitHub Pages
1. Create a free GitHub account/repository named palha-shots.
2. Upload everything INSIDE this folder to the repository root.
3. In the repository: Settings > Pages.
4. Set Source to "Deploy from a branch", choose main and / (root), then Save.
5. GitHub will provide the free public URL.

CHANGING PHOTOS
All optimized website images are in assets/images. The site uses WebP files for quicker loading.

CONTACT / BOOKING
The site currently sends visitors to @palhashots on Instagram. The inquiry builder copies a formatted message to the visitor's clipboard. This avoids requiring a paid form service or publishing an email address.

CURRENT BRAND DIRECTION

- Main line: "Real moments. Thoughtfully captured."
- Baltimore / DMV positioning
- Portfolio categories: Couples, Events, Headshots, Sports, Music, Places & Details
